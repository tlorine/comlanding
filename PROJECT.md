# Studio Landing

## Цель

Профессиональный landing page для студии разработки.

Сайт должен продавать услуги разработки цифровых продуктов,
автоматизации, AI-интеграций и разработки внутренних систем.

## Визуальное направление

Dark Engineering.

- graphite / black background
- amber as accent color
- premium technical aesthetic
- restrained glass effects
- subtle grid
- interactive connected-node system

## Главная визуальная метафора

Система из связанных компонентов.

Сферы — не планеты, а элементы цифровой системы:

- AI
- API
- Database
- Integrations

При взаимодействии с узлом:

- node увеличивается
- связь/орбита становится ярче
- остальные элементы слегка приглушаются
- появляется описание

## Основной message

> Берём задачу и превращаем её в работающий продукт.

## Стек

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion

### Backend

- FastAPI
- PostgreSQL
- Redis — при необходимости

React Three Fiber пока не используем.
Вернёмся к 3D только если обычного CSS/SVG/Motion будет недостаточно.

## Принцип

Не использовать технологии просто ради технологий.

Каждая технология должна решать конкретную задачу.
